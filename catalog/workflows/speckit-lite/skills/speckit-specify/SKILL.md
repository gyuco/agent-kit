---
name: speckit-specify
description: "Write a feature spec (what and why, no tech) in specs/NNN-feature/spec.md. Use when starting a new feature in the Spec Kit lite flow."
---

1. Pick the next number `NNN` and a short slug; create `specs/NNN-slug/spec.md` from `specs/_templates/spec.md`.
2. Describe user scenarios, functional requirements and success criteria — **no implementation details**.
3. Mark every ambiguity as `[NEEDS CLARIFICATION: question]` and ask the user; the spec is ready only when none remain.
